# Unnao Jan Shikayat

A bilingual Hindi/English starter website for citizen complaints.

## Files
- `index.html` — public complaint form and admin login/dashboard
- `style.css` — responsive mobile-friendly design
- `app.js` — Supabase connection, complaint submission, admin dashboard, manual email draft
- `supabase-setup.sql` — starter schema and Row Level Security policies
- `SETUP-HI.txt` — Android setup guide in Hindi

## Important
This is an independent citizen portal starter, not a government website. Public status tracking is intentionally disabled until a secure status-only server endpoint is configured. Never put a Supabase service-role/secret key in browser code. Keep public signups disabled and review the SQL policies before collecting real personal data.
